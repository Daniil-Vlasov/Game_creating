# Идеи событий для будущих актов

Для @game-designer. В игру НЕ внесено. Формат — как `events.json`; цифры — наброски, баланс за дизайнером.
Поля, которых ещё нет в движке, помечены **[новое]** — нужна механика от @coder.
Цель — хардкорный забег 30–45 мин: больше рискованных выборов, цена силы растёт к концу.

## 1. Развилка у межевого камня (акт 1–2, развилка)
Выбор следующего участка тракта — прямо в событии.
```json
{ "id": "crossroads", "title": "Межевой камень", "text": "Тракт двоится. Налево — дым таверны, направо — вороны над курганом. Камень молчит.",
  "options": [
    { "label": "Налево, к дыму", "result": { "routeBranch": "safe" }, "outcome": "Пахнет хлебом. Дорога легче, добыча скромнее." },
    { "label": "Направо, к воронам", "result": { "routeBranch": "risky" }, "outcome": "Туман густеет. Здесь злее враги — и богаче курганы." }
  ] }
```
**[новое]** `routeBranch` — подмена следующих N точек маршрута (лёгкая/опасная ветка).

## 5. Кузнец-отшельник (акт 2, удаление/слияние рун)
```json
{ "id": "hermitSmith", "title": "Кузнец-отшельник", "text": "В пещере стучит молот. Старик сплавляет руны: «Две слабые — одна крепкая. Или выброси лишнее».",
  "options": [
    { "label": "Сплавить две руны (3 зол.)", "cost": 3, "result": { "mergeRunes": 2 }, "outcome": "Две руны стали одной. Колода тоньше, удар крепче." },
    { "label": "Расплавить руну", "result": { "removeRune": 1 }, "outcome": "Руна тает в горне. Тебе её не жаль." }
  ] }
```
**[новое]** `mergeRunes` (две руны одной стихии → сумма Силы), `removeRune` (выбор игрока). Важно для «продуманной сборки».

## 10. Засада на тракте (акт 2, элитный бой по выбору)
```json
{ "id": "ambush", "title": "Засада", "text": "Повозка перевёрнута, на дороге — гоблинские ножи. Из кустов тянет дымом и жадностью.",
  "options": [
    { "label": "Принять бой", "result": { "fight": "goblin", "elite": true }, "outcome": "Гоблины вылетают из кустов. Их больше, чем казалось." },
    { "label": "Обойти лесом (−8 HP)", "result": { "hp": -8 }, "outcome": "Колючки и овраги: −8 HP, но ножи остались позади." }
  ] }
```
**[новое]** `fight` + `elite` — бой из события, усиленный враг и награда выше (например, гарантированное uncommon).
