# Бриф @coder — итерация 1 «Глубина боя»

**Зависит от:** брифа @game-designer (схема `actions` врагов в `enemies.json`).

1. **Намерения врагов** (`src/core/`): модуль `enemyAI.ts` — выбор следующего действия, применение
   (Щит врага, проклятие рун, кража золота, мульти-удар, фазы босса). Без Phaser. В `BattleScene` —
   иконка + число намерения над врагом, Щит врага отдельной полосой.
2. **Справочник комбинаций**: кнопка «?» в бою (≥ 28px) → оверлей со всеми комбинациями из
   `combinations.json` (название, требование, база Атаки/Щита), закрытие касанием.
3. **Подсветка** рун руки, которые попадут в выбранную комбинацию; затемнение проклятых рун.
4. **Развилки (P1, если успеешь):** `route.json` → граф; `WalkScene` короче (≈ 6–8 с), на развилке
   2–3 иконки следующих точек, выбор касанием.

**Правила:** логика в `src/core/`, тексты в `strings.json`, всё в 640×400, только тач, `npm run build` зелёный.
**Критерии приёмки:** намерение видно до хода игрока; справочник открывается за 1 касание; нет ошибок консоли.
