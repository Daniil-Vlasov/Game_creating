# Бриф @game-designer — итерация 1 «Глубина боя»

**Цель:** в бою должны появиться реальные решения и риск; забег — хардкор (30–45 мин в будущем, победа редкая).

**Контекст из ответов владельца (раунд 1):** мало решений, слишком легко/долго, хардкор.
Сейчас враг просто бьёт случайным числом каждый ход, Щит игрока почти всегда перекрывает удар,
босс проходился автоматическими розыгрышами без урона.

**Что сделать (только `src/data/*.json` + согласованные с @coder типы):**
1. `enemies.json`: у каждого врага `actions` — пул/цикл намерений. Типы действий (предложи схему):
   `attack {value}`, `heavy {value, telegraph}`, `block {value}` (Щит врага поглощает Атаку игрока),
   `curse {count}` (проклясть руны в руке — их Сила 0 на ход), `buff {mult}`, `heal {value}`,
   `steal {gold}`, `multi {hits, value}`. Боссу — фазы по HP.
2. Правило темпа: либо лимит розыгрышей на бой, либо «ярость» врага (+N к урону каждый ход). Выбери одно, обоснуй.
3. Пересчитай HP/урон под хардкор. Приложи таблицу в `docs/balance.md`: типичный ход (3–5 рун, без/с
   2 заклинаниями) → урон/щит, ходов на врага, урон по герою за бой.

**Не трогать:** формулу Сила × Множ., стихии, комбинации (кроме баланса чисел), визуал.

**Критерии приёмки:** у каждого врага ≥ 2 типов действий; обычный враг 4–6 ходов, босс 8–10;
без заклинаний забег проигрывается примерно к 4-й точке маршрута.
