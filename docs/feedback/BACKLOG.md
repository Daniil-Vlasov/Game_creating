# Бэклог (ведёт @producer)

Формат: `[P0|P1|P2] @исполнитель — задача. Критерий готовности. (источник)`

## Итерация 1 — «Глубина боя» (v0.2.0)
1. [P0] @game-designer — **Намерения врагов**: у каждого врага цикл/пул действий (удар, тяжёлый удар,
   защита, проклятие руны, усиление, лечение); враги со способностями (слизень делится/лечится, гоблин
   крадёт золото, волк бьёт дважды, призрак проклинает руны, Лич — фазы). Критерий: в каждом бою игрок
   видит намерение на следующий ход и минимум 2 разных типа действий у каждого врага. (р1: мало решений)
2. [P0] @game-designer — **Ограничение ходов и цена ошибки**: Щит врага поглощает Атаку; лимит
   розыгрышей на бой (или растущий урон врага по ходам); хардкор-баланс. Критерий: таблица расчёта —
   обычный враг 4–6 ходов, босс 8–10, без продуманной сборки забег проигрывается к 4-й точке. (р1: легко/долго, хардкор)
3. [P0] @coder — **Понятность**: живое превью «что даст розыгрыш» уже есть → добавить экран-справочник
   комбинаций (кнопка «?» в бою), подсветку рун, которые участвуют в комбинации, разбивку итога по шагам.
   Критерий: из боя за 1 касание открывается список всех 7 комбинаций с требованиями и базой. (р1: непонятно)
4. [P0] @visual-artist + @sound-composer — **«Сок» подсчёта**: счётчики Силы/Множ. «тикают» и растут
   в размере, тряска растёт с итогом, вспышка/частицы на заклинаниях, звук нарастания + финальный «удар»,
   хит-стоп при больших числах. Критерий: розыгрыш на 300+ урона заметно эффектнее розыгрыша на 50. (р1: слабый сок)
5. [P1] @coder — **Развилки на тропе**: короче сегменты (≈ 6–8 с ходьбы), на развилке выбор из 2–3
   следующих точек (иконки над тропой). Критерий: в каждом акте ≥ 3 развилок, маршрут не фиксирован. (р1: тропа)
6. [P0] @qa-reviewer — проверка формул намерений/щита врага, тач, 640×400, сборка, bump до 0.2.0.
