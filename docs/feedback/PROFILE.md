## Платформа и управление
- Xiaomi Pad 6, Chrome, только тач. Игра запускается с GitHub Pages / главного экрана. (ТЗ)

## Визуал
- Вид сбоку, пиксель-арт «получше, покачественнее», не простой. (чат, 2026-11-23)
- Атмосфера «уют с тенью с самого начала»: лайт-фэнтези с намёками на мрак → дарк-фэнтези. (анкета, 2026-11-23)

## Геймплей
- Не клон покера: комбинации из стихий рун, Атака/Щит, Сила × Множитель. (ТЗ)
- Цикл: прогулка по тропе → точки интереса → бой → магазин. (ТЗ)
