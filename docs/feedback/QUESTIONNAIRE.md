# Анкета

## Текущий раунд
_готовит @producer (режим A)_

## Как проходит раунд
1. Основная сессия просит @producer подготовить анкету.
2. Вопросы задаются владельцу в чате (по 4 за экран, с вариантами ответа).
3. @producer обрабатывает ответы → PROFILE, BACKLOG, брифы агентам.
4. Агенты выполняют брифы → @qa-reviewer проверяет → деплой → плейтест → новый раунд.
