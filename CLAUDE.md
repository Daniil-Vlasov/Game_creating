# Тропа Рун — CLAUDE.md

2D пиксельный карточный рогалик для планшета **Xiaomi Pad 6** (16:10, только тач) в фэнтези-сеттинге.
Атмосфера: **«уют с тенью»** — с первых шагов тёплые тракты и таверны с намёками на мрак (руины, вороны, туман);
по мере забега мир плавно темнеет до дарк-фэнтези, но тёплые огоньки надежды остаются до конца.
Камера: **вид сбоку** с многослойным параллаксом.

## Стек
- TypeScript (strict) + Phaser 3.90 + Vite 7. Без внешних аудио/графических файлов (пока): всё процедурно.
- Виртуальное разрешение **640×400**, `Phaser.Scale.FIT`, `pixelArt: true`, `roundPixels: true`.
- `base: './'` в `vite.config.ts` — обязательно для GitHub Pages.
- PWA: `public/manifest.json` (landscape, fullscreen) + `public/sw.js`.
- Деплой: `.github/workflows/deploy.yml` → GitHub Pages при пуше в `main`.

## Команды
- `npm run dev` — дев-сервер (`--host`, можно открыть с планшета в локальной сети).
- `npm run build` — `tsc --noEmit` + сборка. **Должна проходить без ошибок перед каждым коммитом.**
- `npm run preview` — предпросмотр сборки.
- QA-параметр: `?node=N` — начать забег с N-й точки маршрута (проверка тёмных этапов).

## Архитектура
```
src/
  data/      JSON-контент (единственный источник цифр и текстов): cards, combinations, spells,
             enemies, route, events, strings
  core/      чистая логика без Phaser: типы, колода, комбинации, подсчёт, GameState
  scenes/    Phaser-сцены: Boot → Title → Walk → (Battle → Shop | Encounter) → Walk …
  ui/        виджеты (кнопки, панели, верхняя полоса), визуал карт/слотов, фоны, оверлеи
  visual/    палитры (лайт→дарк), процедурный пиксель-арт, пиксельный шрифт
  audio/     SoundEngine.ts — Web Audio синтезатор (SFX + генеративная музыка)
```
Зависимости только сверху вниз: `scenes → ui → visual/core/audio`, `core` ни от чего не зависит (кроме `data`).

## Правила
1. **Только тач.** Никаких hover-зависимых механик; кнопки срабатывают на `pointerup` внутри; цели ≥ 24px.
2. **UI не выходит за 640×400.** Метка билда — правый нижний угол, пиксельный шрифт 3×5.
3. **Контент — в JSON.** Числа, названия, описания — в `src/data/*.json`, строки UI — в `strings.json`.
4. **Формула:** Атака = (Сила атаки) × (Множ. атаки); Щит = (Сила щита) × (Множ. щита).
   Огонь/Воздух → Сила атаки, Земля/Вода → Сила щита. Затем заклинания слева направо.
5. **Не покер.** Комбинации строятся на стихиях рун и последовательностях Силы.
6. Редкости: common, uncommon, rare, legendary, cursed (большой бонус + штраф `penalty`).
7. Перед финальным коммитом — bump patch-версии в `package.json` (делает @qa-reviewer).
8. Язык игры и документации — русский. Код/идентификаторы — английский.

## Субагенты (`.claude/agents/`)
- `game-designer` — механики, баланс, JSON.
- `coder` — TypeScript/Phaser код, разделение core/scenes.
- `visual-artist` — палитры, пиксель-арт, вёрстка 640×400, промпты для нейрогенерации ассетов.
- `sound-composer` — Web Audio SFX и музыка.
- `qa-reviewer` — ревью, проверка сборки, версия.
- `balance-simulator` — симуляция тысяч забегов, отчёт `docs/balance-report.md` с рекомендациями.
- `playtester` — Playwright-прогон на экране планшета, скриншоты, `docs/playtest/REPORT.md`.
- `lore-writer` — тексты и лор в JSON, `docs/lore/BIBLE.md`.
- `producer` — анкеты мнений владельца → профиль предпочтений, бэклог, брифы агентам (`docs/feedback/`).

## Цикл итерации
1. @producer готовит анкету → основная сессия задаёт вопросы владельцу (AskUserQuestion).
2. @producer обрабатывает ответы → `docs/feedback/BACKLOG.md` и брифы `docs/feedback/briefs/*.md`.
3. Исполнители по брифам: game-designer → coder → balance-simulator (замер) → game-designer (правка чисел) →
   visual-artist / sound-composer / lore-writer.
4. @playtester (скриншоты, ошибки) → @qa-reviewer: сборка, ревью, bump версии → коммит → пуш в `main` (автодеплой) → плейтест на планшете.
