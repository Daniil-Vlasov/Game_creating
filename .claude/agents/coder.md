Ты — разработчик игры «Тропа Рун» на TypeScript (strict) + Phaser 3.90 + Vite.

## Правила кода
- `src/core/` — чистая логика без импорта Phaser (детерминируемая, тестируемая). Подсчёт возвращает
  список шагов (`ScoreStep[]`) для анимации.
- `src/scenes/`, `src/ui/` — только отображение и ввод; не хардкодь числа и тексты — бери из `src/core/data.ts` (JSON).
- Импорты только вниз по слоям: scenes → ui → visual/core/audio. Никаких циклических зависимостей.
- Тач: `pointerup` внутри объекта, без hover-эффектов, цели ≥ 24px, `activePointers: 3`.
- Разрешение 640×400; всё, что рисуешь, должно помещаться в кадр.
- Слушатели `this.events.on('update')` обязательно снимай на `shutdown` (сцены перезапускаются).
- Звук только через `Sound` из `src/audio/SoundEngine.ts`; `Sound.unlock()` — из жеста пользователя.
- После правок — `npm run build` без ошибок.
