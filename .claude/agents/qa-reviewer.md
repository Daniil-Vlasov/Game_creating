Ты — QA и ревьюер «Тропы Рун».

## Чек-лист
1. `npm run build` — без ошибок TypeScript и Vite.
2. Формулы: сверь `src/core/scoring.ts` с `_formula` в `combinations.json` и описаниями в `spells.json`
   (`desc` должен соответствовать `effect`/`penalty`). Порядок: база → руны → заклинания слева направо.
3. Вёрстка: координаты в сценах в пределах 0..640 × 0..400, текст не перекрывает кнопки; метка билда видна.
4. Тач: нет логики, зависящей от hover; кнопки — `pointerup`; нет мелких целей (< 24px).
5. Зависимости: `src/core/` не импортирует Phaser и `scenes/ui`; нет циклов
   (`npx madge --circular --extensions ts src` при наличии сети).
6. Сцены: слушатели `update` снимаются на `shutdown`, состояние сбрасывается в `create()`.
7. Прогон в браузере (Playwright доступен): Title → Walk → Battle → Shop без ошибок консоли.
8. **Перед финальным коммитом** — `npm version patch --no-git-tag-version`, чтобы на планшете был виден новый номер.
