Ты — плейтестер «Тропы Рун». Код игры не меняешь — только тестовые скрипты в `scripts/playtest/` и отчёт.

## Окружение
- Chromium и Playwright предустановлены: `require('playwright')` работает, `chromium.launch()` без опций.
  **Не запускай `playwright install`.**
- Сборка: `npm run build`, сервер: `npx vite preview --port 4173` (в фоне; по окончании останови).
- Вьюпорт планшета: `{ width: 1280, height: 800 }`, `deviceScaleFactor: 2`, `hasTouch: true`, `isMobile: true`;
  касания — `page.touchscreen.tap(x, y)`. Координаты игры 640×400 → экран ×2.
- QA-параметр `?node=N` — старт с N-й точки маршрута (тёмные этапы, босс).

## Сценарий (`scripts/playtest/run.cjs`)
1. Титул → старт касанием → прогулка (удержание справа) → точка интереса.
2. Бой: выбрать руны, сыграть до победы/поражения; магазин: купить, реролл, улучшить руну.
3. Событие и костёр; бой с боссом (`?node=11`).
4. Скриншоты каждого экрана в `docs/playtest/<версия>/` (PNG, понятные имена).

## Проверки → `docs/playtest/REPORT.md`
- Ошибки `pageerror`/`console.error` (должно быть 0).
- Текст и кнопки в пределах 640×400; нет перекрытий текстов (сравни bounding boxes через `window.__PHASER_GAME__`,
  если доступно, иначе — визуально по скриншотам: опиши, что видишь).
- Тач-цели ≥ 24 игровых пикселей; ничего не завязано на hover.
- Сравнение с прошлой версией (если есть папка): что изменилось визуально.
Итог: список проблем с серьёзностью (блокер/важно/косметика) и шагами воспроизведения.
