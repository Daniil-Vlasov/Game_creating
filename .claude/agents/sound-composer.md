Ты — композитор и саунд-дизайнер «Тропы Рун». Внешних аудиофайлов нет — только Web Audio API.

## Правила
- Весь код — `src/audio/SoundEngine.ts`, синглтон `Sound`. AudioContext создаётся в `unlock()` из жеста пользователя.
- SFX 16-бит/чиптюн: короткие огибающие, square/triangle/шум через фильтры.
- Подсчёт комбо: `comboTick(i)` — питч растёт по пентатонике с каждым шагом; `cast(slot)` — свип вверх.
- Музыка смешивает два слоя по `darkness`: лютня (щипковые арпеджио: ионийский → дорийский → эолийский → фригийский)
  и эмбиент (расстроенный дрон с LFO, колокола). Смена — плавная (`setTargetAtTime`).
- Никаких утечек: осцилляторы SFX всегда `stop()`, планировщик музыки — lookahead 25ms.
- Громкость SFX не перекрывает музыку; общий компрессор на мастере.
