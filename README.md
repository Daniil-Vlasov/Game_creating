# Тропа Рун

## ▶ [ИГРАТЬ — daniil-vlasov.github.io/Game_creating](https://daniil-vlasov.github.io/Game_creating/)

**На планшете:** открой ссылку выше в Chrome → коснись экрана, игра развернётся на весь экран.
Чтобы появился значок на рабочем столе — на титульном экране нажми **«Установить на планшет»**
(или в Chrome: ⋮ → «Добавить на главный экран»).

---

Пиксельный фэнтези карточный рогалик для планшета (Xiaomi Pad 6, 16:10, тач).
Phaser 3 + TypeScript + Vite, процедурная графика и звук, PWA, автодеплой на GitHub Pages.

```bash
npm install
npm run dev      # http://localhost:5173 (и в локальной сети)
npm run build
```

**Установка на планшет:** откройте GitHub Pages-ссылку в Chrome → меню → «Добавить на главный экран».
Игра запустится в полноэкранном альбомном режиме. Номер билда — в правом нижнем углу.

**Включение Pages:** Settings → Pages → Source: *GitHub Actions*.
